# 中医常见问题和回答 - 脾胃篇

#### 脾虚体质有哪些典型症状？

脾虚主要表现为食欲不振、腹胀便溏（大便稀溏不成形）、四肢乏力、容易疲劳、面色萎黄或苍白、舌淡苔白有齿痕、脉象细弱。脾虚患者往往食欲尚可但运化无力，吃一点就腹胀，且容易出现大便次数增多、大便黏腻。儿童脾虚还常见形体消瘦或虚胖（腹大）、肌肉松软、容易感冒。脾虚日久可累及气血生化不足，出现头晕眼花、心悸失眠等气血两虚的症状。

#### 脾虚应该如何从饮食上调理？

脾虚饮食原则是"定时定量、温和清淡、易消化"，宜少食多餐，避免生冷、油腻、甘甜、厚味的食物。推荐多吃山药、茯苓、白扁豆、莲子、薏苡仁、芡实等健脾食材，可用山药薏米粥（鲜山药100g、薏苡仁30g、粳米50g）作为日常食疗。脾阳虚（手脚冰凉、喜温喜按）可加干姜、肉桂；脾气虚（乏力明显）可加党参、黄芪。忌食冰淇淋、冰镇饮料、西瓜、苦瓜、螃蟹等寒凉食物，以及糯米、年糕等黏腻难消化之物。饮食温度以温热为佳，进食速度宜慢，细嚼慢咽以减轻脾胃负担。

#### 脾虚常用的经典方剂有哪些？

脾气虚首选四君子汤（人参/党参、白术、茯苓、甘草），若伴有食少便溏、脘腹胀满可改用参苓白术散。脾阳虚（畏寒肢冷、脘腹冷痛）用理中丸或附子理中汤。脾虚湿盛（身重困倦、舌苔白腻、大便黏腻）用参苓白术散加藿香、佩兰，或平胃散。脾虚下陷（中气下陷、久泻脱肛、胃下垂）用补中益气汤。若脾虚肝气犯胃（胁肋胀痛、嗳气反酸）用逍遥散合四君子汤加减。需在中医师辨证指导下使用，不建议自行长期服用。

#### 日常生活中如何养护脾胃？

养护脾胃重在规律与节制。第一，饮食有节：定时定量吃饭，七八分饱为宜，切忌暴饮暴食或过度饥饿，睡前2小时不进食。第二，起居有常：坚持早睡早起（建议22点前入睡），适度运动如散步、八段锦、太极拳以促进脾胃运化功能，避免久坐久卧。第三，情志调摄：忧思过度伤脾，应保持心情舒畅，避免长期焦虑抑郁，可通过听音乐、冥想、户外散步等方式疏解情绪。第四，腹部保健：每日晨起或睡前顺时针摩腹5-10分钟（从右下腹→右上腹→左上腹→左下腹），可促进胃肠蠕动。第五，避免外邪：注意腹部保暖，空调房内不露脐，季节交替时注意增减衣物以防寒湿侵袭脾胃。

#### 脾虚患者如何观察舌象和脉象？

脾虚舌象以"淡"为主，舌色淡红或淡白，舌体胖大边有齿痕（舌体两侧被牙齿挤压形成的印痕），舌苔薄白或白腻。若舌苔转黄腻厚，提示湿浊化热或食积化热，需调整调理方案。脉象方面，脾虚常见缓脉（脉来一息不足四至，约每分钟60-70次）、细脉（脉细如线，应指明显）或弱脉（细软无力），与实证（滑脉、弦脉）不同。脾虚湿盛时可见濡脉（细软而浮）。建议脾虚患者可每晨起后对着自然光观察自己舌象，连续观察1-2周舌象变化趋势，以此作为日常自我监测和与中医师沟通的参考依据。
