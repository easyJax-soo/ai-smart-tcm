# 中医常见问题和回答 - 肠道篇

#### 便秘有哪些常见证型及表现？

便秘在中医分为虚实两大类，实证包括热秘（面红身热、口干舌燥、小便短赤、大便干硬如羊屎）、气秘（腹胀肠鸣、欲便不得、嗳气频作、胸胁胀满）、冷秘（手足不温、腹部冷痛、得温痛减、小便清长、舌淡苔白）。虚证包括气虚秘（排便无力、努挣汗出、气短乏力、便后疲倦、舌淡苔薄白）、血虚秘（大便干结如栗、面色无华、头晕心悸、唇甲淡白、舌淡苔白）、阴虚秘（大便干结如粒、形体消瘦、潮热盗汗、五心烦热、舌红少苔）、阳虚冷秘（排便困难、腰膝酸冷、畏寒肢冷、小便清长、舌淡胖苔白滑）。判断自己是哪种便秘是调理的第一步，可根据上述症状描述对照自查，若症状复杂建议就医辨证。

#### 常见便秘如何通过饮食调理？

饮食调理便秘需先辨证再选择食材。热秘（面红口干便干）宜用凉润食物，推荐香蕉（1-2根/日，最好熟透有斑点者）、火龙果（白肉每次半个，红肉清热更强）、菠菜（焯水后凉拌或做汤）、黑芝麻（研末每次10g冲服）；忌辛辣温热食物（辣椒、花椒、姜、羊肉、狗肉）。气秘（腹胀便不出）宜用行气食物，推荐白萝卜（生吃或煮汤，消食下气）、陈皮（泡茶或入粥，每次3-5g）、玫瑰花茶（疏肝解郁，每次3-5朵）；忌糯米、豆制品等易胀气食物。虚证便秘（乏力面色差）宜用补益食物，推荐黑芝麻核桃粥（黑芝麻30g、核桃15g、粳米50g煮粥）、松子仁（每日10-15g嚼服）、蜂蜜（温水冲服，每次1-2勺，糖尿病者慎用）；忌生冷瓜果。冷秘（畏寒便软）宜用温通食物，推荐核桃（每日3-5个）、肉苁蓉（煲汤，每次10g）、韭菜（温阳通便）。无论哪种便秘，每日饮水不少于1500ml，清晨起床后喝300ml温水是最简单有效的通便习惯。

#### 慢性腹泻（脾虚泄泻）有哪些表现？

脾虚泄泻是慢性腹泻最常见的证型，表现为大便溏薄（稀软但不成形）、大便次数增多（每日2-4次或更多）、食后即泻（饭后马上想上厕所）、腹痛隐隐喜温喜按、大便中可见未消化食物残渣。同时伴有脾虚全身症状：面色萎黄或苍白、神疲倦怠、四肢乏力、食欲不振、脘腹胀满、舌淡苔白或有齿痕、脉细弱。脾肾阳虚泄泻（"五更泻"）表现为黎明时分（约3-5点）腹部冷痛、肠鸣即泻、泻后则安，伴有畏寒肢冷、腰膝酸软、夜尿增多。脾虚泄泻与急性肠炎（湿热泄泻：大便臭秽、肛门灼热、腹痛拒按、舌红苔黄腻）截然不同，脾虚泄泻以虚为主，急性期不宜盲目止泻，需先清湿热。

#### 脾虚泄泻和肠易激综合征如何调理？

脾虚泄泻的调理核心是健脾温阳、分清泌浊。第一，饮食严格管控：忌生冷（冰品、凉菜、冰箱取出即食）、忌油腻（油炸食品、肥肉、奶油制品）、忌产气（豆类、薯类、花椰菜）、忌乳制品（牛奶及奶酪，部分脾虚者不耐受）。推荐食物：炒薏苡仁（健脾止泻优于生用）、炒山药、炒白扁豆、芡实、茯苓、莲子（各15g煮粥晨起服）。第二，中药调理：参苓白术散（脾气虚泄泻首选）或附子理中丸（脾肾阳虚泄泻）可在中医师指导下服用。肠易激综合征（IBS，特点是腹泻便秘交替、腹痛与情绪相关）属于肝郁脾虚证，常用痛泻要方（白术、白芍、陈皮、防风）合参苓白术散加减。第三，生活调理：腹部保暖（尤其脐周）、艾灸足三里（外膝眼下三寸）、中脘（脐上四寸）、神阙（脐中）每周2-3次、摩腹（逆时针，顺时针为泻逆为补）、规律作息（23点前睡）、调畅情志（情绪与肠道功能直接相关）。第四，功能训练：养成定时排便习惯（如每日早餐后30分钟，无论有无便意均如厕蹲坐5分钟），建立肠道的条件反射。

#### 肠易激综合征（IBS）特殊人群如何应对？

女性IBS患者症状往往与月经周期相关，经前雌激素下降导致肠道蠕动紊乱加重，表现为经前腹泻加重、经期腹痛明显。建议在月经前一周开始用玫瑰花3g、月季花3g、陈皮5g泡茶疏肝解郁，配合热敷下腹部。老年IBS患者（60岁以上）因脾胃功能衰退、肾阳渐虚，腹泻便秘交替多见，且容易发展为脾肾阳虚型，饮食应以温软烂熟为原则，推荐莲子粥、芡实粥、山药南瓜糊等健脾养胃食物，避免生冷硬食物，必要时用济川煎（肉苁蓉、当归、牛膝、泽泻等）温肾通便，在中医师指导下使用。儿童IBS需特别注意，幼儿脾胃本就娇嫩，不宜用重手法治疗，以饮食调理（少零食、定时定量、戒饮料）为主，配合小儿推拿（补脾经、揉足三里、摩腹）。IBS伴焦虑抑郁患者（长期压力大、情绪低落、睡眠差）是肝郁脾虚的典型代表，建议在上述调理方案基础上加疏肝解郁食疗（菊花枸杞茶：菊花3朵、枸杞子10粒），同时建议寻求专业心理疏导配合中医辨证调理，身心同治效果最佳。
